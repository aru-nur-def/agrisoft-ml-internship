# Agricultural Dataset Analysis - Internship Project

## Description
This project was completed during an industrial internship at AgriSoft.

The goal of the project was to analyze an agricultural dataset and evaluate machine learning training results.

## Tasks
- Dataset analysis
- Visualization of annotated images
- Analysis of training results (CSV)
- Graphical representation of metrics

## Technologies
- Python
- Pandas
- Matplotlib

## Results
The dataset contains a large number of annotated objects.  
The training results show that the model improves over time.
